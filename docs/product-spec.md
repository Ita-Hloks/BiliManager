# 产品功能与交互规格（Product Spec）

本文档定义 BiliManager 的产品定位、功能规格与行为边界。对于当前仓库尚未与目标规格对齐的部分，文中会显式标注 **【当前实现偏差】**，供后续迭代与重构对照（汇总见 [tech-debt.md](./tech-debt.md)）。

---

## 1. 产品定位与核心原则

- **产品定位**：面向 Bilibili 的本地专注力与高质量信息检索伴侣——通过过滤低质搜索结果、用用户自己的收藏夹内容反向置换干扰卡片、净化播放页推荐与记录观看时间，实现“少一点干扰，多一点专注”。
- **隐私红线**：所有设置、规则、黑名单、收藏夹缓存与观看记录**全部保存在本地 `chrome.storage.local`**，不使用 `chrome.storage.sync`，不向开发者或任何第三方上传数据。

---

## 3. 功能域详细规格

### 3.1 搜索结果过滤与屏蔽列表

- **适用页面**：`https://search.bilibili.com/all` 与 `https://search.bilibili.com/video`。
- **搜索质量过滤规则**（`searchFilter`）：
  - **过滤搜索热榜**：默认开启，隐藏搜索页热榜模块。
  - **播放量下限**：默认 `0`（关闭），可配置范围 `0 ~ 1,000,000,000`，低于阈值触发过滤。
  - **弹幕 / 播放互动率下限**：默认 `0.5%`（`0.005`），可配置范围 `0% ~ 1%`（步进 `0.001%`）；仅当播放量 `> 0` 且弹幕数 `> 0` 时计算 `弹幕数 / 播放量`（弹幕为 0 不触发）。支持“直接加遮罩过滤”或“仅降为黑白”（开启过滤时强制连带开启黑白处理）。
  - **未命中搜索词**：检查标题是否包含搜索关键词粉色高亮（或 `<em>`），以下两种情况予以豁免：**UP 主名与搜索词完全匹配**（NFKC + 小写比较），或**属于 UP 主视频推荐卡片**。支持“直接加遮罩过滤”或“仅降为黑白”。
  - **过滤课程标签**：默认开启，识别付费课程卡片标记。
- **屏蔽列表规则**：
  - **标题过滤词正则 / UP 主过滤词正则**：在设置页以列表编辑，底层以 `|` 拼接并用 `new RegExp(pattern, "i")` 匹配；若正则语法无效，不中断页面其余过滤，并在 Popup 顶部横幅提示具体错误。
  - **一键屏蔽 UP 主**：搜索结果卡片（非严格移除状态下）右下角悬浮“屏蔽”按钮，点击后弹出确认面板将 UP 主加入 `uploaderBlocklist`；匹配优先级为 `mid` 精确匹配优先，无 `mid` 时回退到归一化昵称匹配。可在设置页弹窗中搜索或解除屏蔽。
- **两种互斥拦截模式**：
  1. **默认遮罩与门控模式（`strictInterception = false`）**：
     - 命中规则的卡片封面模糊灰化、标题与元信息降对比度、禁用 hover 预览播放，并覆盖显示具体过滤原因。
     - **右键三态解锁机制**（`filterGate`）：卡片默认处于 `locked` 态，捕获拦截点击、中键与 Enter/Space 导航；右键点击一次进入 `peek` 态（提示“再次右键显示封面，之后可点击进入”，清晰展示原标题与元信息）；再次右键进入 `unlocked` 态（隐藏遮罩允许点击跳转）；第三次右键恢复 `locked`。点击页面内其他视频卡片时，已解锁的过滤卡片会自动重新锁定。
     - **收藏夹置换推荐（`favoriteRecommendation`）**：仅在 `locked` 态且开启收藏夹推荐（默认开启、默认比例 `35%`、支持多收藏夹 ID 合并去重）时生效。按稳定哈希比例将部分过滤卡片表面替换为收藏夹视频（封面、标题、UP、发布日期及“收藏夹”角标），点击直接在新标签页打开该收藏夹视频；对替换后的卡片使用右键，仍可切入原卡片的 `peek` / `unlocked` 解锁流程。
  2. **严格拦截模式（`strictInterception = true`）**：
     - 命中规则的卡片直接从布局中移除，并在原位保留 Comment 占位节点以便规则调整或关闭开关时原地还原。
     - **与收藏夹推荐互斥**：开启严格拦截后，命中过滤规则的卡片直接移出 DOM，**不会展示收藏夹替换视频**（【当前实现偏差】设置页 UI 尚缺明确互斥说明，见 [tech-debt.md](./tech-debt.md)）。
- **搜索页即时控制与临时放行（`bypassBar`）**：
  - 当搜索页存在被过滤、黑白降权、正则错误或处于临时放行状态时，在搜索排序条件栏下方、结果网格上方展示行内控制条（`#bili-manager-search-bypass-bar`），实时显示过滤/降权计数。
  - 点击 **「临时放行」**：仅在当前标签页内存中暂缓本次搜索结果卡片的过滤与降权（恢复所有遮罩、灰化与严格移除的卡片，并保留右键/悬浮屏蔽 UP 菜单可用），不影响全局总开关、播放页或计时器设置。
  - **自动复位边界**：点击 **「恢复过滤」** 可立即重新启用过滤；当用户变更搜索关键词、关闭页面或刷新页面时自动复位，也可点击 `×` 在本次搜索期间隐藏该提示条。

### 3.2 播放页个性化

- **适用页面**：`https://www.bilibili.com/video/BV*`、`https://www.bilibili.com/video/av*` 与 `https://www.bilibili.com/bangumi/play/*`（其中“进入视频时关闭弹幕”仅作用于普通视频页 `/video/`）。
- **行为项**：
  - **移除推荐视频列表**：隐藏播放器右侧推荐列表与播放结束浮层，并在播放结束时暂停视频；开启此项时自动联动强制开启“关闭推荐自动连播”。
  - **关闭推荐自动连播**：自动检测连播开关状态并模拟点击关闭（含短暂防重复触发保护）。
  - **进入视频时关闭弹幕**：针对每个新打开的视频（按 BV/av 号去重），若弹幕开关处于开启状态则自动点击关闭，最多尝试 3 次。
  - **移除播放器广告**：隐藏右侧广告卡片、底栏横幅、滑动广告位及活动推广模块。

### 3.3 观看计时器与 Popup 数据看板

- **计时规则（`playerWatchTimer`）**：
  - 在播放页检测到 `<video>` 处于真实播放中（`!paused && !ended && readyState > HAVE_CURRENT_DATA`）即开始计时。
  - **前/后台拆分统计**：页面可见（`document.visibilityState === "visible"`）计入**前台时长**，切到后台标签页或最小化窗口继续播放（如听歌/听播客）计入**后台时长**；二者之和等于总观看时长。
  - **有效记录阈值**：单次播放会话累计超过 **3 秒**（`3000ms`）才记入观看历史与视频列表；支持跨午夜自动日切，活跃会话中断恢复有效期为 **12 小时**。
  - **浮层交互**：展示当前视频累计时长与今日总计，支持鼠标拖拽调整并记忆位置、支持设置页调节背景透明度（`45% ~ 100%`）、页面全屏时自动隐藏；点击浮层右上角 `×` 弹出二次确认后可关闭计时器功能。
- **Popup 看板（`popupApp`）**：
  - **顶部控制栏**：显示运行状态徽章、设置页入口与全局总开关（切换后实时通知当前活动页生效）。
  - **统计图表（`StatsCard`）**：
    - 支持切换 **观看时长**（堆叠/对比柱状图，区分前台蓝色与后台琥珀色，支持切换总计/前台/后台视图）与 **观看数量**（折线图）。
    - 支持切换时间维度：**近 7 天** / **本月**（按周） / **本年**（按月），底部展示与前一日/前一周/前一月的环比差值与百分比。
    - 在 **近 7 天** 柱状图下点击任意日期柱子，下方列表切换为“当日观看时长 Top 3 视频”（支持按总计/前台/后台排序下钻）；再次点击同一日期恢复显示“最近观看”列表。

### 3.4 连续观看定时器（休息提醒）

- **适用页面**：普通视频页与番剧播放页。
- **计时口径**：与观看计时器不同，休息提醒**仅在页面可见（前台）且视频处于播放中**时累计连续观看时间。
- **参数范围**：
  - **连续播放时间**：默认 `60` 分钟，范围 `1 ~ 720` 分钟。
  - **连续观看间隔**：默认 `10` 分钟，范围 `1 ~ 120` 分钟；当停止前台播放（暂停/切后台/关闭页面）超过该间隔后，累计时长自动清零进入新周期。
- **触发动作**：达到连续播放时间上限后，自动暂停页面所有 `<video>`、若处于全屏则退出全屏、清零本次累计周期，并弹出全屏模态提醒框（按 Esc 或点击“知道了”关闭）。

### 3.5 界面主题、自定义背景与数据管理

- **扩展界面主题**：支持跟随系统 / 浅色 / 深色三种模式，作用于 Popup 与 Options 页面。
- **自定义页面背景**：
  - 支持在设置页上传图片，前端 Canvas 自动缩放至长边不超过 `1920px` 并压缩为 `image/jpeg`（质量 `0.82`，上限约 `4.5MB` data URL）。
  - 作用于主要 B 站页面（搜索页、首页、视频页、列表页、番剧、专栏、动态、空间、消息），支持调节遮罩浓度（`0 ~ 1`）与焦点坐标（`0% ~ 100%`），遮罩底色（深色板岩蓝 / 浅色纯白）自动跟随 B 站页面当前主题。
- **数据导入与导出**：
  - JSON 备份格式固定 `app: "BiliManager"`, `schemaVersion: 1`，支持按 `all`（全部数据）、`settings`（设置配置）、`watchHistory`（观看历史）三种粒度导出与导入。
  - **背景保留规则**：导出便携配置时剥离 `customBackground.imageDataUrl` 与定位/透明度参数；导入配置时保留当前设备已有的自定义背景设置。
  - **纯文本规则导入**：导入非 JSON 的 `.txt` 等纯文本内容时，自动按换行拆分并覆盖为标题过滤词正则（`|` 拼接）。
  - **目标规格（UP 屏蔽列表备份）**：`all` 与 `settings` 备份**应包含 `uploaderBlocklist`**，导入时恢复或合并已屏蔽 UP 主列表（**【当前实现偏差】** 当前 `src/options/dataTransfer.ts` 尚未导出/导入 `uploaderBlocklist`，见 [tech-debt.md](./tech-debt.md)）。
